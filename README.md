 How to Run this Project:
Step 1: Copy the Source Code
Copy all the Java source code files from this repository.

Step 2: Open VS Code
Open Visual Studio Code.

Paste the copied source code into a new file named Studentdetails.java.

Save the file.

Step 3: Open CMD
Press Windows + R.

Type cmd and hit Enter to open the Command Prompt.

Step 4: Navigate to Your Project Directory
In CMD, type the following command:
cd\moumita

Step 5: Type the following and press Enter:
javac Studentdetails.java

Step 6: Type the following and press Enter:
java Studentdetails

Step 7: Login
You will see the login page.
Use the following credentials:
Username: admin
Password: admin1234
